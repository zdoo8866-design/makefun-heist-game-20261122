**MIDNIGHT VAULT** is a top-down stealth heist game built for make.fun's
["Make the best heist game"](https://make.fun/bounty/best-heist-game-20261122-0559)
bounty. Slip past guards and security cameras, crack the vault, grab the
Midnight Star, and escape before the alarm catches you.

Pure Canvas 2D with ES modules — no external libraries. The game runs
entirely in the browser.

## How to play

- **WASD / Arrow keys** — move
- **Shift** — sneak (slower, harder to spot)
- **E** — pick up loot / crack the vault lock
- **R** — restart the run

Avoid guard sight cones and camera sweeps. Getting spotted raises the
alarm; reach the vault, take the Midnight Star, and get back to the exit
to win.

## Run locally

```bash
node serve.ts
```

Then open <http://localhost:8080> in your browser.
